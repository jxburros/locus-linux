# Locus Linux integration plan

The canonical plan is maintained locally at
[../../docs/integration-plan.md](../../docs/integration-plan.md).
It owns the M0–M6 gates, current status, boot architecture, and native migration
contracts. [../../docs/readiness-plan.md](../../docs/readiness-plan.md) tracks
image/kernel R0–R5 work. No document in another repository overrides these.

This shell lives at `locus/shell/` in the Linux repository. Its source, tests,
identity, architecture, design, and roadmap are complete local development
inputs. The old cross-repo plan's 2026-07-10 state assessment is superseded by
that plan's current-state table and the local executable contracts.
